
# Arduino Serial Data Visualizer

A dashboard to send and recieve serial data for Arduinos, ESP32s, and other microcontrollers/serial devices.


## Acknowledgements

 - [GD Serial](https://github.com/SujithChristopher/gdserial)
 - [Graph 2d](https://github.com/LD2Studio/godot4-graph2d)

## Features

- Line graph of incoming data
- Serial output
- Serial messager
- Customizable macros
- Variable monitor
- Export data to CSV
